# 邮政行业包 · 总体语境（postal-context）

> 适用：中国邮政（国有企业）内部使用，含**代理金融**与**寄递**两条主要业务线。
> 层级结构：网点/区县 → 地市 → 省公司（强层级、层层上报）。

## 关键语境（载入后替换通用模板的「语境」部分）
- **国企合规**：受银保监、邮政集团制度约束；代理金融尤其强调合规底线。
- **层级汇报**：公文/会议纪要规范，重大事项逐级上报，注意措辞与留痕。
- **党建融入**：基层党建、思想政治工作可作为管理抓手（思想动态、榜样激励）。
- **普遍服务**：邮政承担普遍服务义务，服务民生，维稳与口碑同等重要。
- **稳团队**：国企用工相对稳定，管理更重「情理法」平衡，避免简单粗暴。

## 使用方式
本文件作为 `active_pack: postal` 时的全局语境，加载后所有诊断默认带入上述背景；
具体话术与高频事件见 `agency-finance.md`（代理金融）与 `delivery.md`（寄递）。
