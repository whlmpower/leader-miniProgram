# 管理方格（Blake-Mouton）

## 一句话定位
管理者的行为可落在「关心生产（任务）」与「关心人（关系）」两个维度上，不同组合形成不同管理风格。

## 两个维度
- **关心生产 / 任务导向**：对目标、进度、质量的关注程度。
- **关心人 / 关系导向**：对团队成员需求、情绪、成长的关注程度。

## 典型风格（9×9 简化为四角 + 中庸）
| 风格 | 任务 | 关系 | 特征 |
|------|------|------|------|
| 任务型 (9,1) | 高 | 低 | 重结果、轻人情，易高压 |
| 乡村俱乐部型 (1,9) | 低 | 高 | 重和谐、轻结果，易散漫 |
| 中庸型 (5,5) | 中 | 中 | 折中、求稳 |
| 团队型 (9,9) | 高 | 高 | 目标共识 + 团队赋能（理想态） |

## 锚点映射（对应 anchored-scales.yaml 的 down_task / down_relation）
- 任务维度 A/B（低）+ 关系维度 A/B/C/D → 偏任务型隐患
- 任务低 + 关系高 → 乡村俱乐部型
- 任务中 + 关系中 → 中庸型
- 任务高 + 关系高 → 团队型（目标）

## 核心洞察
基层管理者常因压力大而滑向「任务型」，忽略关系；或因想当好人而滑向「乡村俱乐部型」。先做自我诊断：我偏向哪一格？我想去哪一格？

## 适用诊断场景
管理者自我风格诊断、团队氛围紧张、过度管控、团队执行力与凝聚力失衡。

## 话术方向（供 action-templates 引用）
- 从任务型补关系：「我注意到大家最近压力很大，咱们先停一下，聊聊你们遇到的困难。」
- 从俱乐部型补任务：「咱们目标进度有点落后，我想和大家对齐一下关键节点。」
