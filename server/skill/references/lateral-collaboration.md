# 横向协调（利益相关者管理 + 影响力）

> **成熟度标注：实践框架 / 可操作技巧（非因果科学）**
> 输出时请弱化声明：「影响力技巧是概率性杠杆，需结合情境灵活使用，且不可用于操纵他人。」

## 一、利益相关者管理（Stakeholder Management）
### 核心
推动跨部门事务时，先识别「谁是关键决策人、谁受影响、谁可能阻挠」，再针对性沟通。

### 关键动作
- **画权力-利益矩阵**：高权力高利益 → 重点管理；高权力低利益 → 令其满意。
- **找到共同利益**：跨部门推动靠「共赢点」而非职权。
- **先建信任再谈事**：无信任基础时，先做小协作建立信用。

## 二、影响力原则（Cialdini，参考框架）
- **互惠**：先提供帮助，创造回报义务。
- **权威**：借助数据、上级背书、专业度增强说服力。
- **稀缺 / 紧迫**：合理呈现时间窗口（不可编造）。
- **一致性**：让对方先做小承诺，逐步推进。

### 适用场景
跨部门推动、无职权的项目协调、争取兄弟部门配合、化解推诿。

### 话术方向（供 action-templates 引用）
- 找共赢：「这个事成了，对你们部门 KPI 也有帮助，因为……」
- 建信任：「上次那个小需求我帮你快速处理了，这次想请你支持……」
- 数据说服：「我们有数据表明，这样改能省 20% 的返工，您看要不要一起推？」
