# GROW 教练模型

## 一句话定位
通过目标（Goal）、现状（Reality）、选项（Options）、意愿（Will）四个步骤，用提问引导对方自己找到答案，而非直接给指令。

## 四步结构
1. **G 目标（Goal）**：你想达成什么？要具体、可衡量。
2. **R 现状（Reality）**：现在是什么情况？有什么阻碍？
3. **O 选项（Options）**：有哪些可行的办法？（多问「还有呢」拓宽）
4. **W 意愿（Will）**：你打算怎么做？何时做？需要什么支持？

## 锚点映射（对应 anchored-scales.yaml 的 grow_reality / grow_goal）
- 现状清晰度 A/B（模糊）→ 先引导 G、R，不急着给行动
- 目标清晰度 C/D（明确）→ 直接进 O、W

## 核心洞察
基层管理者最容易跳过 G 和 R，直接跳到「我建议你……」。更好的方式是先让下属自己说清目标和现状，他的执行意愿会更高。

## 适用诊断场景
一对一辅导、绩效面谈、下属求助、冲突调解、推动下属自主解决问题。

## 话术方向（供 action-templates 引用）
- G：「你希望这次谈话结束时有啥结果？」
- R：「现在这件事卡在哪？能举个最近的例子吗？」
- O：「如果资源不是问题，你会怎么做？」
- W：「下一步你打算什么时候开始？需要我做什么？」
