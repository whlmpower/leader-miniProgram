# 情境领导力（Hersey-Blanchard）

## 一句话定位
领导风格应随下属的「成熟度」——即**能力（能不能）**与**意愿（想不想）**——动态调整，而非一成不变。

## 两个维度
- **能力（Competence）**：下属完成任务的知识与技能水平。
- **意愿（Commitment）**：下属的积极性、信心与内驱力。

## 四种领导风格（S1-S4）
| 风格 | 任务指令 | 关系支持 | 适用成熟度 |
|------|----------|----------|------------|
| S1 指令型 | 高 | 低 | 低能力 + 低意愿 |
| S2 教练型 | 高 | 高 | 低能力 + 高意愿 |
| S3 支持型 | 低 | 高 | 高能力 + 低意愿 |
| S4 授权型 | 低 | 低 | 高能力 + 高意愿 |

## 锚点映射（对应 anchored-scales.yaml 的 down_competence / down_commitment）
- A（新手期）+ A/B/C/D 意愿 → S1
- B（成长期）+ A/B → S2；B + C/D 意愿 → S3/S4（视意愿）
- C（熟练期）+ A/B（低意愿）→ **S3**（最常被误用：此处易错配成 S1）
- C/D（专家期）+ C/D（高意愿）→ **S4**
- D（专家期）+ A/B（低意愿）→ **S3**

## 核心洞察
基层管理者最常见的错误：对「高能力低意愿」的员工仍用 S1 指令型，导致抵触加剧。正确做法是 S3 支持型——少给指令、多给支持、授权其自主。

## 适用诊断场景
新人培养、老员工激励、授权不足、员工积极性下降、团队执行力弱。

## 话术方向（供 action-templates 引用）
- S3：「最近这个项目你做得不错，你觉得哪些部分可以由你自主决定？」
- S4：「这个目标交给你，需要什么支持尽管提，我帮你兜底。」
- S1：「我们按这个步骤来：第一步…，第二步…，我先陪你做一遍。」
