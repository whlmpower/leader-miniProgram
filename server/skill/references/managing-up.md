# 向上管理（Managing Up）+ 金字塔原理（Minto）

> **成熟度标注：实践框架 / 可操作技巧（非因果科学）**
> 输出时请弱化声明：「以下为通用管理实践，效果因人而异，不可替代你的专业判断。」

## 一、向上管理（Managing Up）
### 核心
把上级当「关键客户 / 资源方」经营：理解其风格、预期与压力，主动管理信息流与预期。

### 关键动作
- **摸清领导风格**：结果导向型 / 过程管控型 / 放养型，据此调整汇报节奏。
- **主动同步**：定期汇报进度，提前暴露风险，不让领导「 surprises」。
- **带着方案请示**：提问题同时给 2-3 个选项，并推荐一个，而非只抛问题。

## 二、金字塔原理（Minto Pyramid）
### 核心
汇报先给结论（金字塔顶），再给支撑论据；自上而下表达，结论先行。

### 结构
1. **结论先行**：一句话说清你要什么 / 结论是什么。
2. **归类分组**：3 个以内核心论点，彼此独立、完全穷尽（MECE）。
3. **逻辑递进**：每个论点下用数据/事例支撑。

### 适用场景
临时汇报、争取资源、汇报坏消息、方案汇报、邮件书面沟通。

### 话术方向（供 action-templates 引用）
- 结论先行：「领导，我建议把 A 项目延期两周，理由是……」
- 带选项：「有两个方案，我推荐方案二，因为……您看是否可行？」
- 风险预警：「有个风险想提前跟您同步：……，我计划这样应对。」
