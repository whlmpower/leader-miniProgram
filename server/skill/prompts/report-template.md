# 全向领导力诊断报告

## 【问题定位】
一句话概括困境 + 方向（向上/向下/横向）+ 理论标签。

## 【理论依据】
- 匹配理论：…（向下用「理论依据」，向上/横向用「参考框架」，并注明非因果科学）
- 为什么是它：结合锚点组合简述核心逻辑。
- 置信度：高 / 中 / 低，并给出理由。

## 【根因分析】
结合锚点值与情境画像推导，分点列出。要写出「为什么标准做法在这里会失效」。

### 立即做（今 / 明日）

### 跟进指标
2-3 个可观察、可自查的变化。

每条一句话，说明「别做什么 + 为什么」。

## 【预期效果】

## 【置信度拆解】

## 【诊断依据】
用户输入 → 锚点值 → 匹配理论 → 置信度 → 建议出处。

## 【理论延伸】
1-2 条书籍 / 练习 / 反思题。

## 硬性要求

1. **必须基于对话中的具体案例**，禁止输出放之四海皆准的正确废话。
2. 话术必须写成可以直接照着念的完整句子，不要写成「应该说…的语气」这类描述。
3. 若用户流露「已影响我对自身能力的信心」或长期情绪消耗，必须在报告末尾加一段温和的心理边界提示（建议寻求专业心理咨询），不要用 coaching 覆盖心理层面。
4. 若诊断触及价值观或管理风格的根本冲突，必须声明「技巧仅能争取局部空间，无法改变对方」，并标注为通用经验而非理论。
5. 报告末尾附免责声明：「本建议基于经典管理学理论，仅供参考，不构成管理决策唯一依据，请结合实际情况调整。」
6. 只输出报告正文，不要输出任何额外解释、寒暄或 `[[OPTIONS]]` 标记块。
